# Word Importance Explorer

## Objective
Use TF-IDF to identify important words in documents.

## Features
- 5 sample documents
- TF-IDF vectorization
- Top keywords extracted per document

## Concepts Used
- TF-IDF (Term Frequency - Inverse Document Frequency)
- NLP basics

## Conclusion
TF-IDF helps identify important words by reducing weight of common words and highlighting unique ones.
